## 🎨 The Vision
Most digital invitations are static pages. **INVIO** is a digital atelier where invitations are treated as cinematic experiences. Using high-end motion graphics (GSAP), smooth scrolling (Lenis), and a bespoke design system, we help you tell your story through interactive templates that feel premium and alive.

## 🔥 Key Features

### 🏛️ Interactive Template Marketplace
Browse a curated collection of **18+ unique project templates** categorized by event:
- **Weddings & Valentines**: Elegant, high-contrast, and romantic layouts.
- **Academic & Professional**: Clean, structured, and sophisticated.
- **Birthdays & Celebrations**: Vibrant, modern, and energetic.

### ✍️ INVIO Studio (Direct-on-Canvas)
Our bespoke editing engine allows you to customize your invitation directly on the page:
- **WYSIWYG Editing**: Change text and styles live on the template.
- **Real-time Preview**: See how it looks on mobile and desktop instantly.
- **Smart Publishing**: One-click deployment to a permanent living URL.

### 📊 Comprehensive Dashboard
Manage your digital presence with ease:
- **RSVP Tracking**: Real-time insights into guest attendance.
- **Project History**: Version control for all your invitation drafts.
- **Live Analytics**: Monitor engagement and countdowns.

## 🛠️ The Tech Behind the Magic
While you don't need to touch the code to use INVIO, we take pride in the tech that powers it:
- **Frontend**: Vanilla JS (ES6+), GSAP for premium motion, Lenis for smooth scrolling.
- **Backend & Auth**: Supabase integration for secure user sessions and real-time data.
- **Deployment**: Optimized for serverless performance on Vercel.
